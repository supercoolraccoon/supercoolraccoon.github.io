Privacy policy — Hermes

Applies to the personal application “Hermes” and its access to Google APIs. Last updated 21 November 2026.

1. Who operates this application

Hermes is a personal, single-user application operated by its owner on a private home server. It is not offered to the public, has no registrations and no users other than its owner. Contact: super.cool.raccoon@gmail.com.

2. What Google data the application accesses

Only after the owner himself grants consent, and only for his own Google account, the application can access:

  • Google Drive — to create and manage one folder that holds encrypted backup archives of the application's own configuration, and to read or write files the owner asks it to handle;
  • Google Docs and Google Sheets — to create and edit documents and spreadsheets at the owner's request.

The application does not request Gmail, Contacts, Calendar or any other Google service.

3. How the data is used

Data is used solely to perform the tasks the owner asks for on his own machine. Backups are encrypted locally with a symmetric password (GPG, AES-256) before they are uploaded, so the file content stored in Drive is not readable by anyone without that password. The password is kept by the owner and is never sent to Google.

4. Storage and retention

All data stays in the owner's own Google Drive account and on his own server. Older backup archives are rotated automatically (the ten most recent copies are kept). No copy is stored anywhere else by this application.

5. Sharing

No data is sold, rented, published or shared with any third party. The application makes no requests to advertising, analytics or tracking services. Google user data is not used to train or improve any machine-learning model, and it is not transferred to any other party.

6. Security

OAuth credentials are stored on the owner's own server with file permissions restricted to the owner. Access can be revoked at any time by the owner at myaccount.google.com/permissions, which immediately ends the application's access.

7. Changes

Any change to this policy will be published on this page with an updated date.
